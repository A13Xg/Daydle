# Daydle

**All your daily games. One place.**

Daydle is an iOS-first, installable web app for discovering daily games, launching the original games, tracking pasted share results, viewing public game statistics, and comparing performance with friends.

## Repository guidance

- [IDEA.md](IDEA.md) — product goals, behavior, scope, and architectural invariants.
- [roadmap.md](roadmap.md) — numbered, end-to-end implementation phases and acceptance gates.
- [AGENTS.md](AGENTS.md) — required phase-planning, branch, draft PR, verification, and review workflow.
- [completedPhases/](completedPhases/) — archived, reviewed implementation plans for completed phases.

Start with `roadmap.md` and `AGENTS.md`. Implement a phase only when requested. Detailed visual styling is intentionally deferred; interaction quality, accessibility, and iOS PWA usability are required.
